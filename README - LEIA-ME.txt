INSTALLATION / UPDATE
-------------------------------------------------------------------------------
INSTALL OR UPDATE
1. Extract the complete ZIP and open the Turbo Hunter folder.
2. Open INSTALL TURBO HUNTER.cmd and wait for it to finish.
3. Use the "Turbo Hunter" shortcut on your desktop whenever you want to play.
4. Click START GAME, or enable automatic game launch in the mod's window.

The same installer installs or updates Turbo Hunter. It removes previous
mod-owned Python and libraries first, while preserving your saved settings.
Python installed separately for other programs is left in place.

Requires Windows 10/11 x64 and an internet connection for the first setup.
Download percentages appear in the installer window. You do not need to
install Python manually.

PLAY
Enter a SOLO hunt and click START MOD if it is not already running. Wait for
the on-screen counter to appear. Hunt as usual: Turbo Hunter marks the nearest
animal you have brought down. When you collect it, the count updates and the
marker moves to the next one.

NEED ANOTHER CHECK?
- Press F6 or NUMPAD * once and wait for ANALYZING to finish.
- If you are close to the current marker and still need help, press F6 or NUMPAD *
  again. Turbo Hunter will ask you to examine a blood clue.
- A third press near that marker skips only this animal and moves on.
  Wait for ANALYZING to finish between presses.
- F8 moves the on-screen display to another corner; F9 shows or hides it.

-------------------------------------------------------------------------------
Multiplayer protection

ENABLED  = Allows Turbo Hunter to run only in SOLO and blocks multiplayer.
           This is the recommended setting and is enabled on new installations.

DISABLED = Allows multiplayer at the user's own risk for those who intentionally
           want to play with family or friends.

-------------------------------------------------------------------------------
Manual waypoint protection

ENABLED  = Protects the waypoint manually placed by the player. Turbo Hunter
           waits until it is cleared before using the animal GPS again.

DISABLED = Turbo Hunter can automatically move or recover the reference point.
           This protection is disabled by default on new installations.

-------------------------------------------------------------------------------
Saved settings

Your protection choices, display corner, language and automatic game launch
are saved. Updating or reopening the mod does not change these choices.
Change protection settings while the mod is stopped.

-------------------------------------------------------------------------------
Updates

When a newer version is found on Nexus Mods, a clickable notice opens the
mod's download page. The Update mod button also checks for a newer version.

-------------------------------------------------------------------------------
Uninstall

Use UNINSTALL TURBO HUNTER.cmd, the Uninstall option inside the mod, or
Windows Settings > Apps > Turbo Hunter > Uninstall. This removes the mod,
its settings and the private components installed by Turbo Hunter.

PORTUGUÊS (BRASIL) — PT-BR
===============================================================================

INSTALAÇÃO / ATUALIZAÇÃO
1. Extraia o ZIP inteiro e abra a pasta Turbo Hunter.
2. Abra INSTALL TURBO HUNTER.cmd e aguarde a instalação terminar.
3. Sempre que quiser jogar, use o atalho "Turbo Hunter" na Área de Trabalho.
4. Clique em INICIAR JOGO ou ative a abertura automática do jogo na janela do mod.

O mesmo instalador instala ou atualiza o Turbo Hunter. Ele remove primeiro
o Python e as bibliotecas antigos exclusivos do mod, mantendo suas preferências.
O Python instalado separadamente para outros programas permanece no computador.

Requer Windows 10/11 de 64 bits e internet na primeira instalação.
A porcentagem dos downloads aparece na janela do instalador. Não precisa
instalar Python manualmente.

COMO USAR
Entre em uma caça SOLO e clique em INICIAR MOD, caso ainda não esteja ativo.
Aguarde o contador aparecer na tela. Cace normalmente: o Turbo Hunter marca
o animal abatido mais próximo. Quando você o coleta, a contagem é atualizada
e a marcação passa para o próximo.

PRECISA CONFERIR DE NOVO?
- Aperte F6 ou NUMPAD * uma vez e espere ANALISANDO terminar.
- Se estiver perto da marcação atual e ainda precisar de ajuda, aperte
  F6 ou NUMPAD * mais uma vez. O Turbo Hunter pedirá para examinar uma pista de sangue.
- Um terceiro aperto perto da marcação ignora somente esse animal e
  passa para o próximo. Espere ANALISANDO terminar entre os apertos.
- F8 muda as informações na tela de canto; F9 mostra ou esconde essas informações.

-------------------------------------------------------------------------------
Proteção contra multiplayer

ATIVADA   = Permite o funcionamento somente em SOLO e bloqueia o multiplayer.
            Esta é a configuração recomendada e vem ativada em instalações
            novas.

DESATIVADA = Permite multiplayer por conta e risco do usuário, para quem deseja
             jogar intencionalmente com familiares ou amigos.

-------------------------------------------------------------------------------
Proteção da marcação manual

ATIVADA   = Protege o waypoint criado manualmente pelo jogador. O Turbo Hunter
            espera a marcação ser removida antes de voltar a usar o GPS dos
            animais.

DESATIVADA = O Turbo Hunter pode mover ou reassumir o waypoint automaticamente.
             Esta proteção começa desativada em instalações novas.

-------------------------------------------------------------------------------
Preferências salvas

Suas escolhas de proteção, canto das informações na tela, idioma e abertura
automática do jogo ficam salvas. Atualizar ou reabrir o mod não muda essas
escolhas. Altere as proteções enquanto o mod estiver parado.

-------------------------------------------------------------------------------
Atualizações

Quando uma versão mais recente for encontrada no Nexus Mods, um aviso clicável
abre a página de downloads do mod. O botão Atualizar mod também faz a consulta.

-------------------------------------------------------------------------------
Desinstalação

Use UNINSTALL TURBO HUNTER.cmd, a opção Desinstalar dentro do mod ou
Configurações do Windows > Aplicativos > Turbo Hunter > Desinstalar.
Isso remove o mod, suas preferências e os componentes privados do Turbo Hunter.

简体中文

安装与更新
1. 解压整个 ZIP 压缩包，并打开 Turbo Hunter 文件夹。
2. 打开 INSTALL TURBO HUNTER.cmd，等待安装完成。
3. 以后每次游玩时，点击桌面上的“Turbo Hunter”快捷方式。
4. 点击“启动游戏”，或在模组窗口中启用自动启动游戏。

同一个安装程序可用于安装和更新 Turbo Hunter。更新时会先移除旧版模组
专用的 Python 和依赖库，并保留你的设置。其他程序使用的 Python 不会被移除。

需要 Windows 10/11 64 位系统，首次安装需要联网。
安装窗口会显示下载百分比，无需手动安装 Python。

使用方法
进入单人狩猎；如果模组尚未运行，点击“启动模组”，等待屏幕上显示击杀计数。
正常狩猎即可：Turbo Hunter
会标记距离你最近的已击倒动物。领取猎物后，计数会更新，标记会转到
下一只动物。

需要重新检查？
- 按一次 F6 或数字小键盘的 * 键，等待“正在分析”结束。
- 如果你靠近当前标记，仍然需要帮助，再按一次 F6 或数字小键盘的 * 键。
  Turbo Hunter 会提示你检查血迹。
- 在当前标记附近按第三次，可以跳过这一只动物并继续寻找下一只。
  每次按键之间，请等待“正在分析”结束。
- F8 可以将屏幕上的信息移到另一个角落；F9 可以显示或隐藏这些信息。

-------------------------------------------------------------------------------
多人游戏保护

开启 = Turbo Hunter 只能在单人游戏中运行，并阻止多人游戏。
       这是推荐设置，新安装时默认开启。

关闭 = 允许在多人游戏中使用。希望与家人或朋友一起游玩的人可以自行选择，
       相关风险由使用者自行承担。

-------------------------------------------------------------------------------
手动标记保护

开启 = 保护你在游戏中手动设置的标记。Turbo Hunter 会等待你移除该标记，
       然后再使用动物位置标记。

关闭 = Turbo Hunter 可以自动移动或恢复标记。
       新安装时，此项保护默认关闭。

-------------------------------------------------------------------------------
保存设置

保护选项、屏幕显示位置、语言和自动启动游戏选项都会保存。
更新或重新打开模组不会改变这些选择。请在模组停止时更改保护选项。

-------------------------------------------------------------------------------
更新

在 Nexus Mods 上发现新版本时，会显示可点击的提示，打开模组下载页面。
“更新模组”按钮也可以检查新版本。

-------------------------------------------------------------------------------
卸载

运行 UNINSTALL TURBO HUNTER.cmd，使用模组内的“卸载”选项，或前往
Windows 设置 > 应用 > Turbo Hunter > 卸载。
这将移除模组、设置以及 Turbo Hunter 安装的专用组件。
