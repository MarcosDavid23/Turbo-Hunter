ABOUT TURBO HUNTER
-------------------------------------------------------------------------------
Turbo Hunter helps you track animals you have killed but not yet harvested.
The HUD shows the number of pending kills, while the in-game GPS automatically
points toward the nearest pending body.


INSTALLATION
-------------------------------------------------------------------------------

1. Extract the complete ZIP into a new folder.
2. Do not run the installer directly from inside the ZIP.
3. Run "INSTALAR TURBO HUNTER.cmd" once.
4. Wait for all three steps to finish. The complete process remains visible in
   the CMD window.
5. When installation is complete, the Turbo Hunter menu opens automatically.
6. On future launches, use "INICIAR TURBO HUNTER.vbs".

IMPORTANT:
- Internet access may be required during the first installation.
- If a compatible Python 3 installation already exists, Turbo Hunter may use it.
- If Python or Frida is missing, the launcher will offer to repair it.
- Keep all files together inside the extracted folder.


HOW TO USE
-------------------------------------------------------------------------------

Recommended order:

1. Open Turbo Hunter before or after launching the game.
2. Select Português (Brasil), English, or Simplified Chinese.
3. Keep multiplayer protection enabled.
4. Enter a SOLO hunt.
5. Click START.
6. Wait until the HUD is active and shows KILLS: 0.
7. Hunt normally. When a kill is pending, the GPS automatically marks the
   nearest body.

Keep Turbo Hunter running while you play.


CONTROLS
-------------------------------------------------------------------------------

F6 or NUMPAD * = Searches again for missing kills, refreshes the player's
                  position, and restores the GPS. Press it once and wait for
                  ANALYZING... to finish.

F8              = Moves the HUD between the four corners of the screen.

F9              = Shows or hides the HUD.

F7              = Disabled in this version.


IF A KILL IS MISSING
-------------------------------------------------------------------------------

1. Press F6 or NUMPAD * once.
2. Wait for ANALYZING... to finish.
3. If the kill is still missing, press F6 or NUMPAD * one more time.
4. If the HUD asks you to, inspect a blood clue from that animal.
5. If an error message appears, click STOP.
6. Send the "TurboHunter_Log" ZIP created beside the launcher.

Avoid pressing the key repeatedly while the analysis is running.


SETTINGS AND PROTECTIONS
-------------------------------------------------------------------------------

Multiplayer protection

ENABLED  = Allows Turbo Hunter to run only in SOLO and blocks multiplayer.
           This is the recommended setting and is enabled on new installations.

DISABLED = Allows multiplayer at the user's own risk for those who intentionally
           want to play with family or friends.


Manual waypoint protection

ENABLED  = Protects the waypoint manually placed by the player. Turbo Hunter
           waits until it is cleared before using the animal GPS again.

DISABLED = The Turbo Hunter can automatically move or recover the reference point. 
	   This protection is disabled by default upon installation.


LANGUAGES
-------------------------------------------------------------------------------

- Select the language before starting the mod.
- To change the language, stop Turbo Hunter first.
- With Simplified Chinese selected, the menu is displayed in Chinese, but the
  HUD remains in English because its graphical font supports Latin characters
  only.


IMPORTANT NOTES
-------------------------------------------------------------------------------

- After several animals are killed, the marker may change as you walk because
  it continually selects the nearest pending body.
- Turbo Hunter is designed to work while it is running and connected to the
  game.
- The mod does not block the game based only on the build number.
- Do not move individual files outside the Turbo Hunter folder.


REPAIR
-------------------------------------------------------------------------------

If the launcher reports that Python or Frida is missing, accept the repair.

You can also run the repair manually:

TurboHunter\installer\REINSTALAR TURBO HUNTER.cmd

SOBRE O TURBO HUNTER
-------------------------------------------------------------------------------
O Turbo Hunter ajuda você a acompanhar os animais abatidos que ainda não foram
coletados. O HUD mostra a quantidade de abates pendentes e o GPS do jogo aponta
automaticamente para o corpo pendente mais próximo.


INSTALAÇÃO
-------------------------------------------------------------------------------

1. Extraia o ZIP inteiro em uma pasta nova.
2. Não execute o instalador diretamente de dentro do ZIP.
3. Execute "INSTALAR TURBO HUNTER.cmd" uma vez.
4. Aguarde as três etapas terminarem. Todo o processo fica visível na janela
   CMD.
5. Ao concluir, o menu do Turbo Hunter será aberto automaticamente.
6. Nas próximas vezes, use "INICIAR TURBO HUNTER.vbs".

IMPORTANTE:
- Pode ser necessário acesso à internet durante a primeira instalação.
- Se já houver um Python 3 compatível, o Turbo Hunter poderá utilizá-lo.
- Se Python ou Frida estiverem ausentes, o iniciador oferecerá o reparo.
- Mantenha todos os arquivos juntos na pasta extraída.


COMO USAR
-------------------------------------------------------------------------------

Ordem recomendada:

1. Abra o Turbo Hunter antes ou depois de iniciar o jogo.
2. Escolha Português (Brasil), English ou Chinês simplificado.
3. Mantenha a proteção contra multiplayer ativada.
4. Entre em uma caçada SOLO.
5. Clique em INICIAR.
6. Aguarde o HUD ficar ativo e mostrar ABATES: 0.
7. Cace normalmente. Quando houver um abate pendente, o GPS marcará
   automaticamente o corpo mais próximo.

Mantenha o Turbo Hunter aberto enquanto estiver jogando.


CONTROLES
-------------------------------------------------------------------------------

F6 ou NUMPAD * = Procura novamente abates ausentes, atualiza a posição do
                  jogador e recupera o GPS. Aperte uma vez e aguarde
                  ANALISANDO... terminar.

F8              = Move o HUD entre os quatro cantos da tela.

F9              = Mostra ou oculta o HUD.

F7              = Desativado nesta versão.


SE FALTAR UM ABATE
-------------------------------------------------------------------------------

1. Aperte F6 ou NUMPAD * uma vez.
2. Aguarde ANALISANDO... terminar.
3. Se o abate continuar faltando, aperte F6 ou NUMPAD * mais uma vez.
4. Se o HUD solicitar, examine uma pista de sangue daquele animal.
5. Se aparecer uma mensagem de erro, clique em PARAR.
6. Envie o arquivo ZIP "TurboHunter_Log" criado ao lado do iniciador.

Evite apertar a tecla repetidamente durante a análise.


CONFIGURAÇÕES E PROTEÇÕES
-------------------------------------------------------------------------------

Proteção contra multiplayer

ATIVADA   = Permite o funcionamento somente em SOLO e bloqueia o multiplayer.
            Esta é a configuração recomendada e vem ativada em instalações
            novas.

DESATIVADA = Permite multiplayer por conta e risco do usuário, para quem deseja
             jogar intencionalmente com familiares ou amigos.


Proteção da marcação manual

ATIVADA   = Protege o waypoint criado manualmente pelo jogador. O Turbo Hunter
            espera a marcação ser removida antes de voltar a usar o GPS dos
            animais.

DESATIVADA = O Turbo Hunter pode mover ou reassumir o waypoint automaticamente.
             Esta proteção começa desativada em instalações.


IDIOMAS
-------------------------------------------------------------------------------

- O idioma deve ser escolhido antes de iniciar o mod.
- Para trocar o idioma, primeiro pare o Turbo Hunter.
- Em chinês simplificado, o menu é exibido em chinês, mas o HUD permanece em
  inglês porque a fonte gráfica do HUD contém apenas caracteres latinos.


OBSERVAÇÕES IMPORTANTES
-------------------------------------------------------------------------------

- Ao derrubar vários animais, a marcação pode mudar enquanto você caminha,
  sempre buscando o corpo pendente mais próximo.
- O Turbo Hunter foi feito para funcionar enquanto estiver aberto e conectado
  ao jogo.
- O mod não bloqueia o jogo apenas pelo número da build.
- Não mova arquivos individuais para fora da pasta do Turbo Hunter.


REPARO
-------------------------------------------------------------------------------

Se o iniciador informar que Python ou Frida estão ausentes, aceite o reparo.

Também é possível executar manualmente:

TurboHunter\installer\REINSTALAR TURBO HUNTER.cmd

关于 TURBO HUNTER
-------------------------------------------------------------------------------
Turbo Hunter 可帮助您追踪已击杀但尚未收获的动物。HUD 会显示待收获动物
的数量，游戏内 GPS 会自动指向距离玩家最近的待收获动物。


安装
-------------------------------------------------------------------------------

1. 将完整的 ZIP 文件解压到一个新文件夹中。
2. 不要直接在 ZIP 压缩包内运行安装程序。
3. 运行一次“INSTALAR TURBO HUNTER.cmd”。
4. 等待三个安装步骤全部完成。完整过程会显示在 CMD 窗口中。
5. 安装完成后，Turbo Hunter 菜单会自动打开。
6. 以后启动时，请使用“INICIAR TURBO HUNTER.vbs”。

重要：
- 首次安装时可能需要连接互联网。
- 如果系统中已有兼容的 Python 3，Turbo Hunter 可以直接使用它。
- 如果缺少 Python 或 Frida，启动器会提示进行修复。
- 请将所有文件保留在解压后的同一文件夹中。


使用方法
-------------------------------------------------------------------------------

建议顺序：

1. 可以在启动游戏之前或之后打开 Turbo Hunter。
2. 选择 Português (Brasil)、English 或简体中文。
3. 建议保持多人游戏保护开启。
4. 进入单人（SOLO）狩猎。
5. 点击“开始”。
6. 等待 HUD 启动并显示 KILLS: 0。
7. 正常狩猎。有待收获动物时，GPS 会自动标记最近的尸体。

游戏过程中请保持 Turbo Hunter 运行。


快捷键
-------------------------------------------------------------------------------

F6 或数字键盘 * = 重新搜索遗漏的击杀、更新玩家位置并恢复 GPS。按一次后，
                   请等待 ANALYZING... 完成。

F8               = 在屏幕四个角之间移动 HUD。

F9               = 显示或隐藏 HUD。

F7               = 此版本中已禁用。


如果遗漏了击杀
-------------------------------------------------------------------------------

1. 按一次 F6 或数字键盘 *。
2. 等待 ANALYZING... 完成。
3. 如果仍未找到，再按一次 F6 或数字键盘 *。
4. 如果 HUD 提示，请检查该动物留下的血迹线索。
5. 如果出现错误信息，请点击“停止”。
6. 发送启动器旁边生成的“TurboHunter_Log”ZIP 文件。

分析过程中请不要连续反复按键。


设置与保护
-------------------------------------------------------------------------------

多人游戏保护

开启 = Turbo Hunter 只能在单人（SOLO）模式中运行，并阻止多人游戏。
       这是推荐设置，新安装时默认开启。

关闭 = 允许用户自行承担风险在多人游戏中使用，适合有意与家人或朋友一起
       游戏的用户。


手动标记保护

开启 = 保护玩家手动设置的路径点。Turbo Hunter 会等待该路径点被清除后，
       再次使用动物 GPS。

关闭 = Turbo Hunter 可以自动移动或重新使用路径点。新安装时默认关闭。


语言
-------------------------------------------------------------------------------

- 请在启动模组前选择语言。
- 如需切换语言，请先停止 Turbo Hunter。
- 选择简体中文后，菜单会显示中文；由于 HUD 的图形字体仅支持拉丁字符，
  HUD 仍会显示英文。


重要说明
-------------------------------------------------------------------------------

- 击杀多只动物后，行走过程中标记可能会变化，因为系统会持续选择最近的
  待收获动物。
- Turbo Hunter 必须保持运行并连接到游戏才能正常工作。
- 模组不会仅根据游戏 build 编号阻止运行。
- 请勿将单个文件移出 Turbo Hunter 文件夹。


修复
-------------------------------------------------------------------------------

如果启动器提示缺少 Python 或 Frida，请接受修复。

也可以手动运行：

TurboHunter\installer\REINSTALAR TURBO HUNTER.cmd
