## Turbo Hunter 0.6.0

Kill Tracker & Lost Harvest Finder for **theHunter: Call of the Wild**.

### Changes
- Fixed manual waypoint protection, including waypoints already placed by the player.
- Keeps your protection choices, language, display corner and automatic game launch settings.
- Removes old mod-owned Python and libraries before installing the new files.
- Shows download progress during installation.
- Adds a clickable Nexus notice for newer versions and feedback for manual update checks.
- Fixes uninstallation from inside the mod window.
- Keeps the compact interface with Update, Uninstall and About visible, and separate Activity scrolling.

### Installation or update
1. Download **TurboHunter_0.6.0_NEXUS.zip** below and extract the entire ZIP.
2. Open the **Turbo Hunter** folder and run **INSTALL TURBO HUNTER.cmd**.
3. Use the **Turbo Hunter** desktop shortcut. Click **START GAME**, or enable automatic game launch.

Requires **Windows 10/11 x64** and an internet connection for the initial component downloads. Supports launching through Steam and Epic Games. Your saved settings are preserved during updates; Python installed separately for other programs is left in place.

To remove the mod and its private components, use **UNINSTALL TURBO HUNTER.cmd**, **Uninstall** in the mod window, or Windows Settings > Apps > Turbo Hunter > Uninstall.

The package contains instructions in English, Portuguese (Brazil) and Simplified Chinese. The source code matches the installer package.
